Installation

Get WireSeal running on your system in minutes.

System requirements

  • Ubuntu 20.04+, Debian 10+, Fedora 35+, RHEL 9+, Arch Linux
  • Raspberry Pi OS (Debian-based)
  • Root or sudo access

Desktop App — If you prefer a graphical interface with mouse clicks

Download Desktop App (44 MB)

Run

chmod +x WireSeal-linux-x86_64
./WireSeal-linux-x86_64

Dependencies (if needed)

# Ubuntu/Debian
sudo apt install libgirepository1.0-dev libwebkit2gtk-4.1-dev gir1.2-webkit2-4.1

# Fedora/RHEL
sudo dnf install gobject-introspection webkit2gtk4.1

# Arch Linux
sudo pacman -S webkit2gtk

First launch

  1. Launch the app
  2. Choose Server mode or Client mode
  3. Create your vault passphrase
  4. Set up a PIN for quick unlock
  5. Main screen appears with tabs

Dashboard tabs

  • Dashboard — Server status, connected peers, transfer stats
  • Clients — Add, remove, view QR codes
  • Audit Log — Events, sessions, file activity
  • Security — PIN, TOTP, server hardening
  • Admins — Manage admin users
  • DNS — Split-DNS mappings
  • Backup — Vault backup & restore
  • Settings — Configuration
  • About — Version info

CLI — If you prefer typing commands in terminal

Download CLI (42 MB)

Install

sudo install -o root -g root -m 755 wireseal-cli-linux-x86_64 /usr/local/bin/wireseal

Verify

wireseal --version

Install Script — One-liner install with automatic dependencies

Install

curl -fsSL https://github.com/prashanth-7861/WireSeal/releases/latest/download/wireseal-linux.sh -o wireseal-linux.sh
chmod +x wireseal-linux.sh
sudo ./wireseal-linux.sh

The install script automatically installs WireGuard, Python, and configures the firewall.

Usage (CLI / Script)

Initialize VPN server

sudo wireseal init --subnet 10.0.0.1/24 --port 51820

Creates vault, generates keys, configures firewall

Forward the WireGuard port on your router Required for remote access

To reach your home from outside, add one port-forward rule in your router's admin page. WireSeal configures the server's own firewall + NAT automatically, but it can't change your router for you:

  • Protocol: UDP — WireGuard is UDP, so a TCP rule will not work
  • External / WAN port: the port you picked at init — default 51820
  • Forward to: your server's LAN IP (e.g. 192.168.1.100) on the same port

Changed --port? Forward that port instead. If your ISP rotates your public IP, run wireseal duckdns <name> so clients always find you. Automatic UPnP/NAT-PMP forwarding is on the roadmap.

Open dashboard

sudo wireseal serve

Opens web dashboard at http://localhost:8080

Add client

sudo wireseal add-client alice

Generate QR code for mobile

List clients

sudo wireseal list-clients

Show client QR

sudo wireseal show-qr alice

Display QR code in terminal

Export client config

sudo wireseal export alice --output /tmp/alice.conf

Remove client

sudo wireseal remove-client alice

View status

sudo wireseal status

Show connected peers and transfer stats

Rotate client keys

sudo wireseal rotate-keys alice

Rotate server keys

sudo wireseal rotate-server-keys

Update endpoint (DuckDNS)

sudo wireseal update-dns

Backup vault

sudo wireseal backup-vault /path/to/backup

Lock vault

sudo wireseal lock

Change passphrase

sudo wireseal change-passphrase

View audit log

sudo wireseal audit-log

Terminate VPN

sudo wireseal terminate

Bring down WireGuard interface

Fresh start

sudo wireseal fresh-start

Wipe all data and re-initialize

Troubleshooting

Permission denied

Use sudo before commands.

WireGuard not found

Install: sudo apt install wireguard-tools

Port in use

Use: sudo wireseal init --port 51821

Firewall blocked

WireSeal configures firewall automatically.
