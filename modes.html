Server Mode & Client Mode

One app. Two modes. Build your own VPN.

Understanding the Modes

Server Mode

Host

Runs on a computer at home (or VPS). Creates the VPN server and manages who can connect. Think of it as your home's VPN headquarters.

What it can do

  • ✓ Create WireGuard VPN server
  • ✓ Generate & manage client keys
  • ✓ Create QR codes for easy setup
  • ✓ View connected clients
  • ✓ See bandwidth usage
  • ✓ Revoke client access instantly
  • ✓ Rotate keys on schedule
  • ✓ Backup & restore vault
Cannot do

Cannot connect to other VPN servers — it only accepts incoming connections.

Client Mode

Device

Runs on your laptop, phone, or tablet. Connects TO your home VPN server, giving you access to your home network from anywhere.

What it can do

  • ✓ Connect to WireSeal server
  • ✓ Scan QR code to configure
  • ✓ One-click connect/disconnect
  • ✓ Show connection status
  • ✓ Display transfer stats
  • ✓ Auto-connect on app start
Cannot do

Cannot accept other connections — it only initiates outbound connections to the server.

How They Connect

Your Laptop
→
Client Mode
⇄
Server Mode
→
Home Network

Client Mode devices connect through Server Mode to access your home network. All traffic is encrypted end-to-end via WireGuard protocol.

Quick Start

1

Run Server

Install WireSeal on your home computer or VPS. Choose Server Mode. Set passphrase. Click Start.

2

Get Config

Run add-client or click Clients tab. Get QR code or save config file.

3

Connect

Install on your device. Choose Client Mode. Scan QR or load config. Click connect.

✓

Done

Your device is on your home network. Access files, SSH, cameras — anywhere.
