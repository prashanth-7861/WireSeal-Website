Add to WireGuard

1

Scan QR Code

Get config from your Server Mode dashboard.

  1. Open WireGuard app
  2. Tap + button
  3. Select Scan QR code
  4. Point camera at the QR
  5. Tap Create
2

Import Config File

Use a .conf file saved from your server.

  1. Get config file from server
  2. Open WireGuard app
  3. Tap + button
  4. Select Import
  5. Choose .conf file
